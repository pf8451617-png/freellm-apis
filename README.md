# freellm-apis

Lista de APIs de LLM com tier gratuito, com limites verificados e data de verificação.
Limites mudam sem aviso: confira sempre a página oficial de cada provedor.

| Provedor | Limite gratuito | Documentação |
|---|---|---|
| OpenRouter | Modelos :free: 20 req/min e 50 req/dia (1.000/dia após US$ 10 em créditos) | https://openrouter.ai/docs/guides/routing/model-variants/free |
| Groq | Tier gratuito, limites por modelo | https://console.groq.com/settings/limits |
| Google Gemini | Tier gratuito, limites por projeto no AI Studio | https://ai.google.dev/gemini-api/docs/rate-limits |
| Cerebras | Free Trial com US$ 5 em créditos (não é permanente) | https://inference-docs.cerebras.ai/support/rate-limits |

Verificado em 2026-11-26.
